# JobTra AI チュートリアル

この文書は、JobTra を操作する AI がユーザーに説明するための手順です。AI はユーザーの明示的な依頼なしに本文を上書きせず、変更操作の前に対象と変更内容を説明してください。

## 初回利用

1. 現在の下書きとカテゴリを確認する。
2. 文字数上限と現在の文字数を確認する。
3. まず短い例文を入力し、`analyze_writing` で文字数、構成、冗長表現を確認する。
4. 結果を説明し、ユーザーが希望した場合だけ例文の追加や置換を行う。

## 執筆

`get_writing_context` で現在の本文、選択範囲、STAR 構成を取得できます。文章を書き換える前に、対象範囲、変更理由、変更案を提示してください。既存本文の正本は JobTra の IndexedDB です。

## レビュー

`analyze_writing` を呼び出して、文字数、文章監査、カテゴリ別の構成比、冗長表現を確認します。過去版との比較には `compare_writing_versions` を使います。分析結果は提案として説明し、ユーザーの確認なしに本文へ適用しません。

## 同期

ユーザーが個人 Dexie Cloud の URL を設定している場合、別端末でも同じ URL と同じアカウントを使います。接続設定がない場合はローカル IndexedDB のみで動作します。設定手順は `get_jobtra_cloud_setup_guide` で取得できます。

## 例文を使った実演

ユーザーが実演を希望したら、`get_jobtra_tutorial` で手順を確認し、`apply_tutorial_example` に `confirm: true` を指定して例文を入力できます。入力後は `analyze_writing` を呼び、結果を説明します。既存本文がある場合は、置換ではなく追加を選ぶか、先にユーザーの確認を取ってください。
